사용 원칙 4가지

3. 초보자용 주석이 포함된 전체 VBA 코드

회사 데이터와 AI 사용 시 주의

  • 실제 고객명, 주민등록번호, 전화번호, 이메일, 계좌번호를 공개형 AI에 붙여넣지 않는다.
  • 실제 거래 금액과 계약 조건은 더미 값으로 교체한다.
  • 실제 파일 전체보다 열 이름과 5~10행의 비식별 샘플로 질문한다.
  • 사내 코드·파일·경로를 외부 AI에 제공하기 전에 회사 보안 정책을 확인한다.
  • 비밀번호, API 키, 사내 서버 주소를 코드나 프롬프트에 넣지 않는다.
  • AI 답변은 회사의 승인된 저장 위치에만 보관한다.

오류가 나도 하지 말아야 할 행동

  • 같은 코드를 계속 다시 실행하지 않는다.
  • 원인을 모르면서 오류 줄을 삭제하지 않는다.
  • 보안 설정을 '모든 매크로 허용'으로 영구 변경하지 않는다.
  • 오류를 없애기 위해 On Error Resume Next만 추가하지 않는다.
  • Excel이 멈췄다고 바로 강제 종료하기 전에 강사의 중단 안내를 따른다.
  • 원본 파일에 수정 코드를 바로 시험하지 않는다.
